# Sudakov Construction

Website for Sudakov Construction, general contractor in West Newton, MA.
Single static page (`index.html`), hosted on GitHub Pages.

## Adding a job to "Our work"
1. Put photos in `img/work/<job-folder>/`: `name.jpg` (max 1600px) and `name-sm.jpg` (max 720px, thumbnail). Blur house numbers and plates first.
2. Add an entry to the `work` list in `index.html` (search for `OUR WORK gallery`). The first photo is the large cover.
